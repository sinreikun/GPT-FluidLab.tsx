# セル流体実験台 / Fluid Lab

400 × 224 セルの、ブラウザで動く 2D 流体・機械サンドボックス。React / TypeScript / Canvas。外部 API、サーバー、認証は不要です。

## HTML 一枚で使う

`cell-fluid-lab.html` をダブルクリックしてブラウザで開いてください。CSS・JavaScript・React・アイコンをすべて内包し、インターネット接続・Node.js・Web サーバーは不要です。元のシミュレーションと編集機能をそのまま利用できます。

開発側で `npm run build` を実行すると、このファイルと `dist/index.html` が再生成されます。どちらも単独で配布できます。配布用 HTML を直接編集する代わりに、`src` を編集して再ビルドしてください。

単体 HTML の検証は `CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:standalone`。オフライン状態で `file://` から開き、再生、停止中の配置、ピストン設定、保存・再読み込み、Undo が動き、外部通信がないことを確認します。このクラウド環境では管理ブラウザが `file://` を禁止するため、`STANDALONE_TEST_VIA_HTTP=1` を追加し、HTML の内容だけをブラウザに返す方式で同じテストを実行しています（Web サーバー不要、オフライン状態、外部依存なし）。管理環境内での直接ファイル閲覧は未検証です。保存はブラウザ内なので、HTML を別の場所へ移すと保存領域の扱いが変わる場合があります。

## 開発

Node.js 22 以降（この環境では 24.19.0）、npm を使用します。

```sh
npm ci
npm run dev
```

```sh
npm run test       # エンジンの物理・編集・保存テスト
npm run build      # 型検査と本番ビルド
npm run test:e2e   # Playwright の実操作テスト
```

E2E には Chromium が必要です。通常の環境では `npx playwright install chromium`。クラウド環境では既存の Chromium を利用できます。

```sh
CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e -- --workers=1
```

## 遊び方

初回は見本を表示します。左水槽は水・油・水銀と氷、中央水槽は水と溶岩、上部の箱は水素です。回転パドルと反復ピストンの機械も含みます。

- 物質を選んでドラッグで描画。右クリックはどのツールでも消去。ホイールまたは `[` / `]` でブラシ半径を変更。
- `Space` で再生・停止。停止中も描画・移動・設定可能。`1`〜`0` で物質、消去、壁矩形、壁円、ガイド矩形、ガイド円、可動壁矩形、可動壁円、モーター、ピン。`V` で選択・移動。
- 矩形ドラッグ中の `Shift` で正方形。物質描画中の `Ctrl` / `Cmd` で壁・ガイドを上書き。
- 選択ツールで機械をドラッグ。空白をドラッグして範囲選択。`Shift` + クリックで選択を追加・解除。
- モーターと可動壁を置き、接続位置にピンを置いて「この位置でつなぐ」。プロパティの親リストでも接続可能。循環接続は拒否します。
- 固定関節は親の位置・回転に追従。フリー関節は接続点の移動に追従し、ワールド角度を維持。
- 「温度装置」を選びクリックすると温度調整装置を設置。選択後のプロパティで目標温度（−273〜2,000°C）、影響半径（1〜40セル）、有効／無効を設定できます。＋／−ボタンは10°C刻み。流体を遮らず、再生中だけ周囲を目標温度へ徐々に近づけます。装置は移動・親子接続・削除・Undo・保存に対応し、選択時に影響範囲、盤面上に設定温度を表示します。複数装置の範囲が重なる場合は距離に応じた重みで目標温度を平均します。
- 加熱・冷却ブラシで温度を変更し、温度表示で相変化を観察。矢印やショートカットは入力欄の編集中には盤面に影響しません。
- `Delete` / `Backspace` で選択対象削除、`Ctrl` / `Cmd` + `Z` で Undo、`Escape` で選択解除。編集履歴は最大 40 件。
- 各ウィンドウのタイトルをドラッグして移動、`−` で折りたたみ。狭い画面では折りたたんだ状態から開始。
- 「保存」「読込」は現在のブラウザの localStorage。キー `cell-fluid-lab-v1`、形式 v4。破損・異なるサイズ・古い形式は見本へ戻ります。

## 構造

- `src/components/lab/FluidLab.tsx`: UI、入力、編集トランザクション、固定ステップループ。
- `src/components/lab/engine.ts`: TypedArray のセル状態、熱交換、相変化、流動、剛体ラスタライズ、機械階層、Undo、保存検証。
- `src/components/lab/renderer.ts`: セルのピクセル描画、機械・接続・選択・配置プレビュー。
- `src/components/lab/engine.test.ts`: 密度分離、気体、固体、相変化、熱交換、階層変換、衝突、粒子保存、Undo、保存復元。
- `e2e/lab.spec.ts`: マウス・キーボードでの編集、機械接続、入力欄との競合防止、保存、ウィンドウ、モバイル表示。

React にセル状態を渡さず、物理は 1/60 秒単位、流動はステップごとに 2 回。速度は 1〜3 倍。描画は requestAnimationFrame。編集ドラッグ中は物理を一時的に止め、編集をひとつの Undo にまとめます。停止中の編集結果も即座に描画します。

## 仕様を補完した点と制約

- 壁の押し出しは進行方向側の面から同じ空間を探索し、閉じた空間で退避できない粒子は消さず一時保持。空きができれば復帰。探索は 4,096 セルまでで、逃げ場のない空間の探索結果を同一ラスタライズ内で再利用。
- 高速の機械は 0.75 セル以下の小刻みな姿勢で衝突判定。接触時はそのステップの駆動全体を戻します。ピストンの伸び・折り返しも巻き戻し、成功した高速移動では途中の液体も押し出します。
- 可動壁は固定壁を通過します。ガイドは手動移動・モーター駆動の両方で衝突し、薄いガイドも途中の姿勢で確認して飛び越えを防ぎます。可動壁同士は衝突させません。
- 入力中・ドラッグ中の状態を扱いやすくし、配置上限、保存失敗、ガイド接触などは画面上に説明。
- 定性的なセルモデルです。圧力・非圧縮性・連続流体の速度場・厳密な潜熱や運動量保存は計算しません。粒子の温度は相変化で維持しますが、熱容量は物質に応じて変わります。
- 大量の物質・大型機械・3 倍速では負荷が増え、60 FPS は端末性能次第。追いつけない時間は無限に積み上げず破棄します。
- localStorage はブラウザ単位。Undo と選択状態は保存しません。デスクトップのマウス操作を推奨。狭い画面はウィンドウを折りたたんで利用してください。

特に試してほしい操作: 油・水・水銀の積層、氷の融解と水の沸騰、回転パドルの固定／フリー関節切替、ピストンの起点と伸び、ガイド接触、親子を含む複数選択の移動・削除と Undo。

## 物質ごとの流れ方

物質には粘度・密度とは別に、固体・液体・気体の性質を定義しています。水・油・水銀・溶岩は液体として水面をならす横流れを持ち、低粘度ほど速く広がります。気体は浮力で上昇し、天井付近では拡散して逆さの砂山になるのを抑えます。氷・岩石は固体として形状を維持し、粘度を下げても液体のようには動きません。相変化すると新しい物質の流れ方へ切り替わります。液体・気体の粘度100による手動固定は引き続き使えます。横流れは固定壁・可動壁・異なる物質を飛び越えず、粒子数と温度を移動先へ引き継ぎます。
