# セル流体実験台 / Fluid Lab

ブラウザで物質を置き、熱・機械・反応・分離を組み合わせる2Dサンドボックスです。水素・結晶・抽出液の三系統で、材料を回収して繰り返し使う実験ができます。

**現在は400 × 224セル、最大3成分の混合、CPUによるシミュレーションを実装しています。** 科学計算用のCFDや、実在物質を定量的に再現する化学シミュレーターではありません。

## 起動と最初の実験

1. [cell-fluid-lab.html](cell-fluid-lab.html) をダウンロードし、Chromeなどのブラウザで開きます。GitHubのファイル表示画面ではHTMLは実行されません。
2. 初回は関節と合成・分離を組み合わせた総合見本を表示します。保存済みならその実験を読み込みます。
3. 「実験見本」で「三つの循環」を選び、「見本」を押します。
4. `Space` で再生・停止。装置を選び、流量や電力を変えて挙動を観察します。

配布HTMLはJavaScript・CSS・React・アイコン・Web Workerを内包します。実行にNode.js、Webサーバー、外部API、アカウントは不要で、オフラインでも使えます。保存はブラウザ内です。HTMLを移動した場合などは、以前の保存領域へアクセスできないことがあります。

## 現在の仕様

### セル・物質・熱

| 項目 | 実装済みの内容 |
| --- | --- |
| 盤面 | 400 × 224セル。拡大してもセル数は変わりません。 |
| 物質量 | 1セルの最大容量は1、最大3成分。セル数と物質量は別に表示します。 |
| 液体 | 密度による分離と、水面をならす横流れ。粘度で流れやすさが変わります。 |
| 気体 | 浮上・拡散する簡略モデル。圧力や実在気体の状態方程式は扱いません。 |
| 固体・粉体 | 氷・岩石は形状を維持。晶塩・煤などの粉体は落下して山状に積もります。 |
| 混合 | 対応する組み合わせで接触面から混合。全物質が互いに混ざるわけではありません。 |
| 溶解・析出 | 晶塩などの溶解量を溶媒量と温度で制限。冷却や溶媒の減少で析出します。 |
| 相変化 | 成分ごとに融解・凝固・蒸発・凝縮。必要な熱と生成先の空きを確認します。 |
| 熱 | 熱伝導、熱容量、潜熱・化学的な生成エネルギーの簡略モデル。単位・物性値はモデル用です。 |

混合セルの密度・粘度・熱容量などは成分量から計算します。流動・移送・可動壁による押し出しでも組成を保持します。成分数や容量の上限を超える処理、生成先が塞がった反応は待機します。

### 物質の役割

| 物質 | 主な用途 |
| --- | --- |
| 水・氷・水蒸気 | 溶媒、冷却、相変化、水素循環。 |
| 炭化水素油 | 水と混ざらない軽い液体、燃料。 |
| 水銀・水銀蒸気 | 重く流れやすい液体、高温での相変化・蒸留の比較。 |
| 溶岩・岩石 | 高粘度の融液、冷却による固化。 |
| 水素・酸素 | 燃焼と水の電気分解。 |
| 煤 | 不完全燃焼の生成物。酸素と加熱でさらに燃焼できます。 |
| 二酸化炭素 | 油・煤の燃焼生成物。燃焼を支えません。 |
| 窒素 | 空気の不活性成分。 |
| 晶塩 | 水への溶解・析出、結晶循環、抽出・回収に使う架空の塩。 |
| 活性剤 | 晶塩と反応して複合結晶を作る架空の材料。 |
| 複合結晶 | 沈降・膜分離で回収し、加熱再生できる架空の結晶。 |
| 揮発溶媒・溶媒蒸気 | 水と混ざる架空の低沸点溶媒。65°Cから蒸発し、55°C以下で凝縮。 |
| 抽出液 | 水と混ざらない重い架空の液体。晶塩を運び、回収後に再利用できます。 |

「空気」を塗ると、**酸素23%・窒素77%の有限量の混合物**を配置します。空白から酸素が無限供給されることはありません。パレットは液体・気体・粉体・固体・循環材料で絞り込めます。

### 燃焼と三系統の循環

水素・油・煤は酸素を消費して燃えます。油は酸素不足で煤を生成し、その煤も再燃焼できます。自然着火は温度条件が必要です。酸素不足や生成先の閉塞で停止します。炎は反応中の表示で、独立した物質ではありません。

| 循環 | 流れ | 外部から必要なもの |
| --- | --- | --- |
| 水素 | 水 → 電解 → 水素＋酸素 → 燃焼 → 水蒸気 → 凝縮 → 水 | 電力、冷却 |
| 結晶 | 晶塩＋活性剤 → 複合結晶 → 膜分離 → 加熱再生 → 晶塩＋活性剤 | 加熱用電力、温度調整 |
| 抽出 | 水溶液の晶塩 → 抽出液へ取り込む → 晶塩を水へ戻す → 抽出液を再利用 | 動力、排熱 |

水素・酸素・水の**質量比は1:8:9**。晶塩1＋活性剤1から複合結晶2を生成します。晶塩と活性剤は、条件が合えば装置なしでも溶液中で反応します。逆方向の再生は装置で行います。

複数の生成物が出る反応は、全ての入口・出口を確認してから実行します。一方の出口が満杯でも原料だけ消費することはありません。装置は累計処理量・投入電力・除去熱を表示します。材料の循環はできますが、エネルギー投入なしに動き続ける仕組みではありません。

詳細・各ポートの役割・検証条件は [CYCLES.md](CYCLES.md) を参照してください。

### 機械と流路

- **モーター**：回転・ピストン、速度、正転・逆転・停止、反復を設定。
- **可動壁**：矩形・円。流体を押し出し、固定壁を通過します。ガイドには衝突します。可動壁同士の衝突は扱いません。
- **固定壁**：流体を遮断。**ガイド**：流体を通し、可動壁を制限。
- **関節**：固定・自由・ばね復帰。接続時に支点を自動生成し、選択中のマーカーをドラッグして編集可能。ばねは曲げ角度上限・強さ・減衰を調整できます。
- **温度装置**：目標温度−273〜2,000°C、半径1〜40セル。再生中に周囲を徐々に温度調整します。
- **移送装置**：ポンプ、開閉バルブ、指定成分だけを移送する選択膜。
- **循環装置**：電解槽、着火燃焼器、凝縮器、結晶反応器、結晶再生器、抽出器、回収器の7方式。

接続は子→親の順に指定します。親子関係の循環は禁止です。支点編集・親変更・親削除では、その時点の物体の姿勢を保持します。自由関節は接触で曲がり、ばね復帰はガイドから離れると基準角度へ戻ります。厳密な剛体の慣性・摩擦・トルク計算ではありません。詳細は [JOINTS.md](JOINTS.md) を参照してください。

流路は**指定ポートのセル間を直接移送する方式**です。描かれた線の途中に物質は存在せず、壁を貫く配管として使えます。標準の方向・距離に加え、ポートの相対座標を個別設定できます。独立した配管網や圧力損失は未実装です。

退避場所がない密閉空間ではモーターの駆動を取り消します。編集による重なりなどで押し出せない物質は一時保持し、逃げ場ができると復帰させます。

### 編集・表示・保存

- 描画、装置配置、移動、複数選択、削除、最大40件のUndo。
- 消しゴムはブラシ／矩形範囲に対応。指定物質、相、壁、ガイド、可動壁、装置種類・処理方式で対象を限定できます。
- 混合セルの指定成分だけを消す場合は、残りの量と温度を保持します。右クリックにも消しゴム設定が適用されます。
- 範囲消去は離した時に実行。Escでキャンセル、Undoで復元。独立した範囲選択ツールなら物体の上から選択枠を開始できます。
- キャンバスは50〜800%の拡大縮小、表示移動、100%・中央へのリセットに対応。
- 物質・温度・成分濃度・流れ／装置の観察モード。カーソル位置の組成・量・温度を表示。
- ウィンドウは移動・折りたたみ可能。狭い画面では折りたたんで開始します。
- 保存先はlocalStorage、キーは `cell-fluid-lab-v1`、形式は**v7**。v4〜v6を読み込み、旧ピンを関節情報へ移行します。物質IDは改名後も維持します。
- ファイルへの実験データ書き出し、Redo、Undo履歴・カメラ・ツール設定の保存は未実装です。

### 見本

| 見本 | 内容 |
| --- | --- |
| 合成・分離と関節 | 自由／ばね関節の比較、攪拌・保温・沈殿・膜分離。初回の総合見本。 |
| 三つの循環／各循環 | 材料を補充せず再利用する実験回路。 |
| 関節の比較 | ガイド接触後の自由関節とばね復帰の違い。 |
| 物理の見本 | 密度分離、氷・溶岩、気体、回転パドル、ピストン。 |
| 溶解と析出 | 晶塩の溶解と、温度差による結晶回収。 |
| 混合液の蒸留 | 揮発溶媒の蒸発・移送・凝縮。 |
| 沈殿と膜分離 | 晶塩と活性剤から作った複合結晶の回収。 |

循環の見本は、収支を追いやすい**1セルの閉鎖槽とポート間移送**で構成しています。大きな水槽の中で自律的に流れ続ける工場の見本は、今後の拡張対象です。

## 性能と現在の制約

シミュレーションはCPUのWeb Worker、描画と入力はメインスレッドで実行します。GPU計算は使いません。Workerが利用できない環境では同期実行へ戻ります。

時間刻みは1/60秒、速度指定は1〜3倍です。計算要求は同時に1件、まとめて実行するのは最大2ステップ。高負荷では進行を遅くし、画面操作の応答を保ちます。**60 FPSでも実時間に追従しているとは限りません。** 「進行1.00×」が実時間に相当し、「ms」は1ステップの計算時間です。計測方法と最適化の詳細は [PERFORMANCE.md](PERFORMANCE.md) にあります。

現在の物理・化学は定性的なモデルです。圧力、非圧縮性、連続した速度場、運動量保存、厳密な化学平衡、爆発、電線網、触媒は扱いません。編集による追加・削除、温度ブラシ、温度装置、室温への緩和は外部との物質・熱の出入りです。

## 開発・検証

Node.js 22以降を推奨します。

```sh
npm ci
npm run dev
```

```sh
npm test                 # エンジン・反応・循環・編集・Worker同期のテスト
npm run build            # 型検査、ビルド、単一HTML生成
npm run test:e2e          # Chromiumでのブラウザ操作テスト
npm run test:standalone   # 単一HTMLのオフライン動作テスト
npm run test:perf         # CPU負荷の参考計測（通常テストからは除外）
```

E2EにはChromiumが必要です。通常は `npx playwright install chromium` で導入できます。このクラウド環境では既存のChromiumを使います。

```sh
CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e -- --workers=1
STANDALONE_TEST_VIA_HTTP=1 CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:standalone
```

通常の単一HTMLテストは `file://` を使います。管理ブラウザが直接ファイル閲覧を禁止するこのクラウド環境では、HTMLをローカルのHTTPリクエストへ直接返す方式で検証しています。Webサーバーは立てず、オフライン・外部依存なしで確認します。この環境での直接 `file://` 閲覧は未検証です。

`npm run build` は [cell-fluid-lab.html](cell-fluid-lab.html) と `dist/index.html` を生成します。配布HTMLを直接編集せず、ソースを変更して再ビルドしてください。
