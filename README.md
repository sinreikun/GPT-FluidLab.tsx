# セル流体実験台 / Fluid Lab

400 × 224 セルの、ブラウザで動く 2D 流体・機械サンドボックス。React / TypeScript / Canvas。外部 API、サーバー、認証は不要です。

## HTML 一枚で使う

`cell-fluid-lab.html` をダブルクリックしてブラウザで開いてください。CSS・JavaScript・React・アイコンをすべて内包し、インターネット接続・Node.js・Web サーバーは不要です。元のシミュレーションと編集機能をそのまま利用できます。

開発側で `npm run build` を実行すると、このファイルと `dist/index.html` が再生成されます。どちらも単独で配布できます。配布用 HTML を直接編集する代わりに、`src` を編集して再ビルドしてください。

単体 HTML の検証は `CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:standalone`。オフライン状態で `file://` から開き、再生、停止中の配置、ピストン設定、保存・再読み込み、Undo が動き、外部通信がないことを確認します。このクラウド環境では管理ブラウザが `file://` を禁止するため、`STANDALONE_TEST_VIA_HTTP=1` を追加し、HTML の内容だけをブラウザに返す方式で同じテストを実行しています（Web サーバー不要、オフライン状態、外部依存なし）。管理環境内での直接ファイル閲覧は未検証です。保存はブラウザ内なので、HTML を別の場所へ移すと保存領域の扱いが変わる場合があります。

## 開発

Node.js 22 以降（この環境では 24.19.0）、npm を使用します。

```sh
npm ci
npm run dev
```

```sh
npm run test       # エンジンの物理・編集・保存テスト
npm run build      # 型検査と本番ビルド
npm run test:e2e   # Playwright の実操作テスト
```

E2E には Chromium が必要です。通常の環境では `npx playwright install chromium`。クラウド環境では既存の Chromium を利用できます。

```sh
CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e -- --workers=1
```

## 遊び方

初回は見本を表示します。左水槽は水・油・水銀と氷、中央水槽は水と溶岩、上部の箱は水素です。回転パドルと反復ピストンの機械も含みます。

- 物質を選んでドラッグで描画。右クリックはどのツールでも消去。Shift＋ホイールまたは `[` / `]` でブラシ半径を変更。
- `Space` で再生・停止。停止中も描画・移動・設定可能。`1`〜`0` で物質、消去、壁矩形、壁円、ガイド矩形、ガイド円、可動壁矩形、可動壁円、モーター、接続。`V` で選択・移動。
- 矩形ドラッグ中の `Shift` で正方形。物質描画中の `Ctrl` / `Cmd` で壁・ガイドを上書き。
- 選択ツールで機械をドラッグ。空白をドラッグして範囲選択。`Shift` + クリックで選択を追加・解除。
- モーターと可動壁を置き、接続ツール（0）で子→親の順にクリック。関節の支点は選択中のマーカーをドラッグして編集できます。プロパティの親リストでも接続可能。循環接続は拒否します。
- 固定関節は親の位置・回転に追従。フリー関節は接続点の移動に追従し、ワールド角度を維持。
- 「温度装置」を選びクリックすると温度調整装置を設置。選択後のプロパティで目標温度（−273〜2,000°C）、影響半径（1〜40セル）、有効／無効を設定できます。＋／−ボタンは10°C刻み。流体を遮らず、再生中だけ周囲を目標温度へ徐々に近づけます。装置は移動・親子接続・削除・Undo・保存に対応し、選択時に影響範囲、盤面上に設定温度を表示します。複数装置の範囲が重なる場合は距離に応じた重みで目標温度を平均します。
- 加熱・冷却ブラシで温度を変更し、温度表示で相変化を観察。矢印やショートカットは入力欄の編集中には盤面に影響しません。
- `Delete` / `Backspace` で選択対象削除、`Ctrl` / `Cmd` + `Z` で Undo、`Escape` で選択解除。編集履歴は最大 40 件。
- 各ウィンドウのタイトルをドラッグして移動、`−` で折りたたみ。狭い画面では折りたたんだ状態から開始。
- 「保存」「読込」は現在のブラウザの localStorage。キー `cell-fluid-lab-v1`、形式 v7。v4 は単一成分・量1として移行します。破損・異なるサイズ・不明な物質IDは読み込まず見本へ戻ります。

## 構造

- `src/components/lab/FluidLab.tsx`: UI、入力、編集トランザクション、固定ステップループ。
- `src/components/lab/engine.ts`: TypedArray のセル状態、熱交換、相変化、流動、剛体ラスタライズ、機械階層、Undo、保存検証。
- `src/components/lab/chemistry.ts`: 最大3成分の物質量、溶解・拡散・析出、成分別の相変化とモデル潜熱、反応レシピ。
- `src/components/lab/chemistry.test.ts`: 保存則、溶解・蒸留・沈殿回収、装置閉塞、成分上限、v4→v5移行。
- `src/components/lab/renderer.ts`: セルのピクセル描画、機械・接続・選択・配置プレビュー。
- `src/components/lab/engine.test.ts`: 密度分離、気体、固体、相変化、熱交換、階層変換、衝突、粒子保存、Undo、保存復元。
- `e2e/lab.spec.ts`: マウス・キーボードでの編集、機械接続、入力欄との競合防止、保存、ウィンドウ、モバイル表示。

React にセル状態を渡さず、物理は 1/60 秒単位、流動はステップごとに 2 回。速度は 1〜3 倍。描画は requestAnimationFrame。編集ドラッグ中は物理を一時的に止め、編集をひとつの Undo にまとめます。停止中の編集結果も即座に描画します。

## 仕様を補完した点と制約

- 壁の押し出しは進行方向側の面から同じ空間を探索し、密閉空間で退避できないモーター駆動は取り消します。編集による重なりは消さず一時保持し、空きができれば組成ごと復帰。探索は 4,096 セルまでで、逃げ場のない空間の探索結果を同一ラスタライズ内で再利用。
- 高速の機械は 0.75 セル以下の小刻みな姿勢で衝突判定。接触時はそのステップの駆動全体を戻します。ピストンの伸び・折り返しも巻き戻し、成功した高速移動では途中の液体も押し出します。
- 可動壁は固定壁を通過します。ガイドは手動移動・モーター駆動の両方で衝突し、薄いガイドも途中の姿勢で確認して飛び越えを防ぎます。可動壁同士は衝突させません。
- 入力中・ドラッグ中の状態を扱いやすくし、配置上限、保存失敗、ガイド接触などは画面上に説明。
- 定性的なセルモデルです。圧力・非圧縮性・連続流体の速度場・運動量保存は計算しません。熱容量と相ごとの形成エネルギーによる簡略な潜熱を使い、相変化時に必要な熱を受け渡します。値はモデル内の単位であり、実在物質の定量的な物性値ではありません。
- 大量の物質・大型機械・3 倍速では負荷が増え、60 FPS は端末性能次第。追いつけない時間は無限に積み上げず破棄します。
- localStorage はブラウザ単位。Undo と選択状態は保存しません。デスクトップのマウス操作を推奨。狭い画面はウィンドウを折りたたんで利用してください。

特に試してほしい操作: 油・水・水銀の積層、氷の融解と水の沸騰、回転パドルの固定／フリー関節切替、ピストンの起点と伸び、ガイド接触、親子を含む複数選択の移動・削除と Undo。

## 物質ごとの流れ方

物質には粘度・密度とは別に、固体・液体・気体の性質を定義しています。水・油・水銀・溶岩は液体として水面をならす横流れを持ち、低粘度ほど速く広がります。気体は浮力で上昇し、天井付近では拡散して逆さの砂山になるのを抑えます。氷・岩石は固体として形状を維持し、粘度を下げても液体のようには動きません。相変化すると新しい物質の流れ方へ切り替わります。液体・気体の粘度100による手動固定は引き続き使えます。横流れは固定壁・可動壁・異なる物質を飛び越えず、成分量と熱を移動先へ引き継ぎます。晶塩・活性剤・複合結晶は粒状固体で、落下して山状に積もります。

## 合成・分離の一括導入

変更の計画は [IMPLEMENTATION.md](IMPLEMENTATION.md) に記録しています。

### 実験を選ぶ

ヘッダーの「実験見本」で選び、「見本」を押すと配置します。既存の物理見本も残っています。

| 見本 | 観察すること |
| --- | --- |
| 溶解と析出 | 左槽の晶塩が水へ溶け、攪拌・加熱で速くなる。右槽の温かい溶液を冷やすと結晶が析出する。 |
| 混合液の蒸留 | 左槽を95°Cに保つと水より先にBが蒸発する。上部のポンプが蒸気を右槽へ送り、冷却器で液体溶媒として回収する。 |
| 沈殿と膜分離 | 晶塩と活性剤の溶液が反応して不溶性のEを生成。Eを選択した膜で右槽へ回収する。 |

### 新しい物質

晶塩（水への溶解・温度依存の飽和・析出）、揮発溶媒と溶媒蒸気（水との混合・65°Cで蒸発・55°Cで凝縮）、抽出液（水と混ざらず沈む）、活性剤（水への溶解・晶塩との反応）、複合結晶（不溶性・沈降）を追加しました。これらは架空物質で、選択するとパレットの説明に性質を表示します。

反応比は **晶塩 1 + 活性剤 1 → 複合結晶 2**。5〜180°Cで進み、モデル単位で弱く発熱します。材料は溶液内で接触すれば装置なしでも反応します。生成先が塞がれていれば待機し、成分を破棄しません。

### 機械

「ポンプ」「バルブ」「選択膜」をクリックして盤面へ設置し、選択してプロパティを編集します。

- ポンプ: 矢印の入口から出口へ最大0〜10単位/秒で移送。
- バルブ: 開くと移送し、閉じると中央の7セル幅のゲートで流体を遮断。
- 選択膜: 指定成分だけを移送。溶液から水だけを抜くこともできます。
- 各装置の方向、ポート距離（中心から2〜30セル）、有効／無効を設定可能。物質量・熱は移送元から移送先へ受け渡します。
- 矢印の線は装置内の流路です。入口・出口の間に壁があっても装置内部を通過します。外側の流体が膜を迂回しないよう、容器の壁・仕切りと組み合わせてください。
- 出口満杯、入口遮断、材料不足、成分非対応、流量0、停止の状態を表示します。装置は既存の機械へ親子接続できます。

### 成分と熱

セルの最大容量は1、最大3成分。混合物の密度・粘度・熱伝導率・熱容量は成分量に応じて計算します。混合で上限を超える場合は待機します。セル数と物質量は異なり、ステータスに両方を表示します。混合成分を含むセルの移動・剛体による押し出し・保存・Undoでも成分量を保持します。

水と揮発溶媒は接触面から混合し、水と油・抽出液は混ざりません。溶解量は水の量と温度で制限され、飽和すれば粉が残ります。冷却や溶媒の減少で析出します。満杯の水セルへの溶解は同量の溶媒との交換で開始します。濡れた粉のセルは未溶解部分を含み、主成分が粉の間は粒状固体として動きます。

相変化はセル全体ではなく成分別に行い、生成先の空き容量を確認して少量ずつ進めます。必要な熱が足りなければ相変化量を制限します。たとえば水と揮発溶媒の混合液を95°Cに保つと溶媒だけを蒸留できます。

温度装置・ブラシ・室温への緩和は外部との熱交換です。反応は化学的な生成エネルギーを熱へ変換します。循環装置の投入電力・除去熱は個別に記録します。内部移送・混合・相変化は成分量とモデル内の熱を受け渡し、浮動小数点の丸め誤差を許容して検証しています。

### 表示・保存・拡張

観察モードで「物質」「温度」「成分濃度」「流れ・装置」を切替。成分濃度では観察する物質を選択します。カーソル位置には各成分の比率、量、温度を表示。混合物の通常色は成分比率で合成します。

v7保存は安定した物質IDのカタログと成分量を保持します。v4/v5/v6保存は自動移行し、保存時にv7になります。物質IDが不明、容量超過、循環接続などのデータは状態を一部だけ書き換えず拒否します。

物質の追加は `engine.ts` の `MATERIAL_IDS` と `MATERIALS`、混合・溶解・相変化・反応の追加は `chemistry.ts` の `MISCIBLE_GROUPS`、`SOLUBILITY_RULES`、`PHASE_RULES`、`REACTIONS` を編集します。既存IDは変更しないでください。

### 今回の範囲

最大3成分の混合、酸素を消費する燃焼、電力を投入する電解と結晶再生、抽出・回収を扱います。厳密な化学平衡・圧力・乳化・表面張力、爆発、電線網、触媒機構は扱いません。配管は装置のポート間を結ぶ移送で、通過途中のセルに材料を置きません。


関節は固定・自由・ばね復帰の3種類。ばね復帰はガイドで曲がり、離れると基準角度へ戻ります。角度上限・強さ・減衰を調整可能。旧v4/v5のピンは読み込み時に接続点へ移行します。新しい総合見本と関節比較見本を追加しました。詳細は [JOINTS.md](JOINTS.md)。


CPU性能改善: 計算を内蔵Web Workerへ分離し、親子・ガイド・熱計算の重複と押し出し時の全走査を削減しました。高負荷では進行を遅くして画面操作を保ちます。ステータスの「進行」「ms」で負荷を確認できます。単一HTMLもWorker込みで動作します。計測方法と詳細は [PERFORMANCE.md](PERFORMANCE.md)、`npm run test:perf` を参照してください。


三系統の循環を追加しました。「実験見本」→「三つの循環」→「見本」で、水の電解・燃焼・凝縮、複合結晶の分離・加熱再生、抽出液の回収・再利用を観察できます。材料は補充せず、電力と冷却を投入して循環します。操作と成立条件は [CYCLES.md](CYCLES.md)。保存はv7、旧v4〜v6の物質IDと量は維持して読み込みます。

物質名を晶塩・揮発溶媒・活性剤・複合結晶へ整理し、抽出液は晶塩を運ぶ抽出液に変更。煙は煤に整理し、酸素・二酸化炭素・窒素を追加しました。「空気」の描画は有限量の酸素23%・窒素77%。空白は酸素を供給しません。炎は燃焼中の表示です。油は酸素を使って燃えるため、加熱だけで煙へ変化する旧仕様は廃止しました。


キャンバスはホイールまたは下部の＋／−で50〜800%に拡大縮小できます。カーソルを中心にズームし、中ボタン／Alt＋ドラッグで表示を移動。「移動」ボタンを有効にすると通常のドラッグやタッチでも表示移動ができます。「全体」で100%・中央へ戻ります。ブラシ半径は `[ ]` またはShift＋ホイール。倍率は表示だけに作用し、セル数・シミュレーションの量や速度は変更しません。


消しゴムは「消去対象」で物質全体・指定物質・相（液体／気体／粉体／固体）・固定壁・ガイド・可動壁・装置種類を選べます。混合セルの指定成分だけを削除し、残量と温度を保持。「範囲消去」はドラッグした矩形を離したときに消去します。Escでキャンセル、Undoで復元。右クリックにも同じ消しゴム設定が適用されます。オブジェクト用の独立した「範囲選択」（R）も追加し、オブジェクト上から選択枠を開始できます。
